Last time I've posted about a new machine, on Sep/2008, I was really excited to get an [INTEL Core 2 Quad Q3300](https://programing-fun.blogspot.com/2008/09/here-we-come-again-part-iii-end.html), a 4 cores processor with an whopping 8 GB of DDR2 memory!

Since then, I have replaced my main machine 3 times, so I was curious to compare every single configuration since I started playing with these toys. Even though not remembering all the details it is pretty clear that hardware in general have evolved a lot as one can see below:

![Computer Configurations](./Computer%20Configurations.png "All my computer configurations")

The main takeaways could be summarized as:

1. Processor speeds increased very fast from 1989[^1], my first computer, up until 2002; after that, frequencies took a much slower
   grow pattern and finally stalled.
1. Processor core count, by the other hand, kept expanding up until around 2020[^2]
1. Memory sizes followed processor core count trends, i.e. memory size kept growing
1. Storage size growth pattern matches memory/processor count one
1. In 2006 I was excited buying my first **dual core** CPU :)[^3]


[^1] I know, at that time [486](https://en.wikipedia.org/wiki/I486) were already a thing but I was oblivious about computer models/processors at that time so I ended up buying something I knew at least something :)

[^2] Nowadays, number of cores in mainstream processors are stable

[^3] My dream machine would have a Threadriper with 96 cores but I like my kidneys
